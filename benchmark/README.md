# SpareScript 编程基准

衡量 AI 模型「从一句需求写出能在 Spare 眼镜上跑的应用」的能力。

## 题目

[tasks.jsonl](tasks.jsonl) 每行一道题：

| 字段 | 含义 |
|---|---|
| `id` | 题号 |
| `prompt` | 给模型的需求（中文） |
| `scenario` | 评分用的模拟器场景 |
| `checks` | 自动检查项 |

## 评分

每道题满分 4 分：

| 项 | 分 |
|---|---|
| 编译通过 | 1 |
| 云端构建（含平台压力场景）0 FAULT | 1 |
| `checks` 全部满足（截图 OCR 加日志检查） | 1 |
| 没有违反设计规范（文字在 y ≤ 195 内、没有闪烁、离线时不空白） | 1 |

总分 = 12 题之和 / 48。评测脚本（`run.py`，调用 MCP `build` 和 `simulate`）随 SDK 一起在里程碑 M2 发布。

## 提交成绩

在 Discussions 的「基准成绩」分类里发帖，写明模型、日期、提示词和每题得分。
